## What Is This?

This is a complete Obsidian vault implementing the **Islamic Science Master Learning Framework v5.0**. It transforms the original 50-page study system into an interconnected, searchable, template-driven digital knowledge base designed for serious students of Islamic sciences.

## Getting Started

1. **Open this folder as a vault** in [Obsidian](https://obsidian.md)
2. **Start at** `00 - Home.md` — this is your Map of Content
3. **Read** the Framework Guide pages first (folder `01`)
4. **Fill in** your Master Learning Dashboard (folder `02`)
5. **Record** your teachers in the Sanad Registry (folder `05`)
6. **For each lesson**: create a new note in the subject folder → insert a template with `Ctrl/Cmd + T`
7. **Every Friday**: create a Weekly Review note in folder `10`
