# Level Transition Gates

## Madkhal -> Beginner

- [ ] Recall random Speed Spine in 30 seconds
- [ ] List all 5 masa'il for 3 random lessons
- [ ] Provide primary dalil + wajh for major topics
- [ ] Pass all 4 tatbiq scenarios for 2 random lessons
- [ ] Pass Feynman explanation to a beginner
- [ ] Draw concept map from memory
- [ ] Resolve all SH entries for current level
- [ ] Reach Fahm 3 or 4 on all lessons
- [ ] Complete hasb al-nafs for every lesson
- [ ] Identify 3 cross-subject connections

## Beginner -> Intermediate

- [ ] Recite matn with no major errors
- [ ] Explain any line selected at random
- [ ] Explain author's architecture
- [ ] 30-second recall for each bab theme
- [ ] Recall primary dalil for major sections
- [ ] Define all technical terms introduced
- [ ] Apply content to 10 practical scenarios
- [ ] 50+ Tier-1/Tier-2 Anki cards passing
- [ ] Resolve all SH entries from beginner lessons
- [ ] Fahm 3 minimum across lessons

## Intermediate -> Advanced

- [ ] State precise mahall al-khilaf from memory
- [ ] Give rajih + full reasoning for studied masa'il
- [ ] Steelman opposing view accurately
- [ ] Identify usuli principle behind each tarjih
- [ ] Identify recurring patterns across disputes
- [ ] Analyze sanad and dalalah strength
- [ ] Apply rajih view to new case
- [ ] Zero unresolved SH entries
- [ ] Fahm 3-4 across all intermediate lessons
