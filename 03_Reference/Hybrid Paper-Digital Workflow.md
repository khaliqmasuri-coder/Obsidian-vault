# Hybrid Paper + Digital Workflow

## What Stays on Paper

| Section | Why Paper Works Better |
|---|---|
| Speed Spine | Handwriting improves motor-memory encoding |
| 5 Masa'il | Physical space enforces synthesis discipline |
| Tasawwur | Fast visual thinking and sketching |
| Athar al-Qalb / Du'a | Slower writing improves sincerity/reflection |
| Matn memorization lines | Repetitive handwriting supports hifz |
| Rough tatbiq answers | Better for freeform thought |
| Concept maps | Spatial architecture is easier by hand |

## What Stays Digital (Obsidian)

| Section | Why Digital Works Better |
|---|---|
| Tafsil overflow | Collapsible detail without clutter |
| Master Shubuhat Log | Searchable, sortable, taggable |
| Conflict Register | Easy linking to lesson notes |
| Khata Log | Filter and pattern analysis |
| Master Dashboard | Fast updates and weekly planning |
| Cross-subject integration | Bidirectional linking |
| Sanad registry | Search and reference links |

## Sync Protocol (within 24 hours)

- [ ] Scan/photo handwritten pages (`Subject_Lesson#_Date`)
- [ ] Move Speed Spine into Anki Tier-1 card
- [ ] Add new SH entries to [[Master Shubuhat Log]]
- [ ] Add new CR entries to [[Conflict Register]]
- [ ] Update [[Master Dashboard]] (lesson # + Fahm level)
- [ ] Add rawabit links in Obsidian
- [ ] Move overflow detail into digital notes

## Backup Rule

- Weekly cloud sync + local backup copy.
- Photograph full notebooks before archiving.
