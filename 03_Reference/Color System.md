# Functional Color System (v5)

Use each color for exactly one meaning.

| Color | Meaning | Use For | Never Use For |
|---|---|---|---|
| Red | Foundation / Stop | Non-negotiable principles, core anchors | Decoration |
| Yellow | Must-know cold | Speed Spine, memory-critical evidence | Lookup-only details |
| Green | Heart / spiritual | Du'a, khashyah, raghbah, adab impact | Purely academic detail |
| Blue | Evidence / Dalil | Qur'an, hadith, ijma', wajh al-dalalah | General principles |
| Orange | Warning / doubt | Shubuhat, errors, conflict flags | Attention-seeking emphasis |
| Purple | Cross-reference | Links across subjects and lessons | New analysis |
| Black | Reference only | Long detail, source tracing, overflow | Primary study spine |

## Fast Rule

If color meaning is mixed, retrieval quality drops and review speed collapses.
