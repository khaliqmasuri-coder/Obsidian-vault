# Daily Study Engine (20-minute minimum)

## Non-Negotiable Daily Block

| Minutes | Activity | Tool | Duration | Done |
|---|---|---|---|---|
| 1-5 | Speed Spine recall (3 random past lessons) | Notebook / Anki | 5 min | ☐ |
| 6-12 | New lesson OR rapid review | Framework notes | 7 min | ☐ |
| 13-17 | Tatbiq out loud (yesterday scenario) | Voice / notes | 5 min | ☐ |
| 18-20 | Athar al-Qalb review + du'a | Notes | 2 min | ☐ |

## Weekly Architecture (default)

- Saturday: New Aqidah
- Sunday: New Fiqh
- Monday: New Tafsir
- Tuesday: New Hadith
- Wednesday: New Adab
- Thursday: Catch-up / deep dive / Q&A
- Friday: [[Weekly Review Protocol]]

# Anki Card Creation System

## Tier Map

| Tier | Card Type | Tests | Review Frequency |
|---|---|---|---|
| 1 | Speed Spine -> Answer | Core lesson mastery | Daily until Fahm 4 |
| 2 | Dalil -> Ruling | Evidence recall | Every 3 days |
| 3 | Mas'alah -> Masa'il set | Lesson architecture recall | Every 7 days |
| 4 | Error Detection | Correction + principle | Every 14 days |
| 5 | Feynman Card | Plain-language teaching | Every 30 days |

## Card Rules

1. One concept per card.
2. Create cards from memory after lesson completion.
3. Test production (not recognition).
4. Tag cards: `#subject #level #lesson_number`.
5. If failed 3 times consecutively, move to re-study and redo the lesson.
