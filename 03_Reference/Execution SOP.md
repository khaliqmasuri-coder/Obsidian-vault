# Execution SOP (Framework-Faithful)

## Before Every Session

1. Open [[Master Dashboard]].
2. Run [[Pre-Lesson Protocol]].
3. Choose mode correctly (first-study / rapid-review / deep-dive).

## During Lesson

1. Capture Ustadh signals live.
2. Write exactly 5 Masa'il.
3. Build Speed Spine from memory only.
4. Complete Tatbiq out loud.
5. Set honest Fahm level.

## Immediately After Lesson

1. Set review dates (D1, D3, D7, D14, D30).
2. Set `next_review` to nearest pending gate.
3. Log SH/CR items.
4. Complete one Hasb al-Nafs action.

## Daily Minimum

- Run [[Daily Study Session Template]] (20 min non-negotiable).

## Friday

- Run [[Weekly Review Protocol]].
- Resolve highest-priority SH/CR.
- Update next week plan.
