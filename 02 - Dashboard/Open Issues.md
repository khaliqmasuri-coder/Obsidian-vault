## Resolution Workflow

1. **Identify** — Write the issue precisely in the table above
2. **Classify** — Is it a Shubhah (doubt), Conflict (contradiction), or Gap (missing knowledge)?
3. **Log** — Add to [[Master Shubhat Log|Master Shubhāt Log]] (SH-XXX) or [[Conflict Register]] (CR-XXX)
4. **Refer** — Ask your teacher if needed. Record who you asked.
5. **Resolve** — Write the resolution in the log. Check the box.
6. **Verify** — Can you now explain this clearly? If not, it is not resolved.
