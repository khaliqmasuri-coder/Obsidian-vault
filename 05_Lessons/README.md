# Lessons Folder

Store all real lesson notes here so dashboards and subject indexes auto-detect them.

## Required Frontmatter (minimum)

```yaml
---
type: lesson
subject: aqidah
level: madkhal
lesson_no: 1
study_date: 2026-03-08
mode: first-study
fahm: 1
status: active
next_review: 2026-03-09
---
```

## Naming Format

`SUBJECT - LXX - Short Title`

Example: `Aqidah - L03 - Tawhid al-Uluhiyyah`
