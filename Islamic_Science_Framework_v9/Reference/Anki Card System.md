# 🃏 Anki Card System

## Tiering
1. **Tier 1 (daily):** Speed Spine -> full recall
2. **Tier 2 (every 3 days):** Dalil -> ruling/principle
3. **Tier 3 (every 7 days):** 5 Masāʾil recall
4. **Tier 4 (every 14 days):** Error detection and correction
5. **Tier 5 (every 30 days):** Feynman-style plain explanation

## Rules
- One concept per card.
- Write cards from memory after lesson completion.
- Test production, not recognition.
- Tag cards: `#subject #level #lesson_number`.
- If a card fails 3 times, re-study the parent lesson.
