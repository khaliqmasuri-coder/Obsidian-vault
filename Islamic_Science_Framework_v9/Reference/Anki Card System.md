# 🃏 Anki Card Creation System — Spaced Repetition Done Right

> [!caution] Anki is only as good as the cards you put into it.
> Most students make cards that test **recognition**, not **recall**. These templates produce cards that force true retrieval.

---

## Card Tiers

### 🟡 Tier 1 — Speed Spine → Answer

| Field | Content |
|---|---|
| **What it tests** | Core mastery: "this lesson establishes that ___" / "Evidence is ___" / "Matters because ___" |
| **Review frequency** | **DAILY** until ④ Fahm |
| **Front example** | "Al-ʿAqīdah al-Wāsiṭiyyah Lesson 3 — this lesson establishes that..." |
| **Back example** | Full Speed Spine |

### 🔵 Tier 2 — Dalīl → Ruling

| Field | Content |
|---|---|
| **What it tests** | Evidence recall: given this āyah/ḥadīth, what ruling/principle does it establish? |
| **Review frequency** | Every **3 days** |
| **Front example** | "Sūrah al-Baqarah 2:286 — what principle does this establish in ʿaqīdah?" |
| **Back example** | [wajh al-dalālah] |

### 🔴 Tier 3 — Masʾalah → Masāʾil

| Field | Content |
|---|---|
| **What it tests** | What are the 5 masāʾil for Lesson X? |
| **Review frequency** | Every **7 days** |
| **Front example** | "List the 5 masāʾil for [Lesson Title]" |
| **Back example** | All 5 with color codes |

### 🟠 Tier 4 — Error Detection

| Field | Content |
|---|---|
| **What it tests** | What is the mistake in this statement? Which principle corrects it? |
| **Review frequency** | Every **14 days** |
| **Front example** | [Statement with a flaw] |
| **Back example** | Identification + correction + dalīl |

### 🟢 Tier 5 — Feynman Card

| Field | Content |
|---|---|
| **What it tests** | Explain [concept] to a 10-year-old in 2 sentences |
| **Review frequency** | Every **30 days** |
| **Front example** | "Explain tawakkul to someone with zero background" |
| **Back example** | Your best plain-language explanation |

---

## Card Creation Rules

> [!danger] Follow these strictly — bad cards waste more time than no cards.

1. **One concept per card.** If you need more than 2 sentences on the back, split the card.
2. **Always write the card from memory AFTER completing the lesson** — not while taking notes.
3. **Cards must require PRODUCTION** (write or speak the answer) — not recognition (true/false).
4. **Tag every card:** `#subject` `#level` `#lesson_number` — so you can filter by what you're studying.
5. **If you fail a card 3 times in a row**, move it to a "Re-study" deck and re-do the full lesson.
