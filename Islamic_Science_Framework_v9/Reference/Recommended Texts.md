# 📚 Recommended Texts

## 🔴 Aqidah
- Madkhal: Al-Usul al-Thalathah / Al-Qawa'id al-Arba'
- Beginner: Kashf al-Shubuhat / Lum'at al-I'tiqad
- Intermediate: Al-Wasitiyyah / Al-Hamawiyyah
- Advanced: Al-Tadmuriyyah / Dar' Ta'arud al-'Aql wal-Naql

## 🔵 Fiqh
- Madkhal: Umdat al-Fiqh (selected) / Al-Muqarrab
- Beginner: Al-'Umdah al-Fiqhiyyah / Zad al-Mustaqni'
- Intermediate: Al-Kafi / Al-Muqni'
- Advanced: Al-Mughni + Usul pathway

## 🟢 Tafsir
- Madkhal: Muqaddimah fi Usul al-Tafsir + selected surahs
- Beginner: Tafsir al-Sa'di / abridged Ibn Kathir
- Intermediate: Expanded Ibn Kathir + Ulum al-Qur'an basics
- Advanced: Al-Itqan / Al-Burhan

## 🟡 Hadith
- Madkhal: Al-Arba'un al-Nawawiyyah + hadith sciences intro
- Beginner: Umdat al-Ahkam / Nukhbah basics
- Intermediate: Bulugh al-Maram / Nukhbah commentary
- Advanced: Fath al-Bari selections / 'Ilal studies

## 🟣 Adab
- Madkhal: Adab al-Mufrad (selected) / Riyad al-Salihin (selected)
- Beginner: Adab al-Mufrad (complete)
- Intermediate: Madarij al-Salikin (selected)
- Advanced: Madarij (deeper) / Al-Ruh
