# 🚪 Level Transition Gates

## Madkhal -> Beginner
- [ ] 30-second Speed Spine recall (random lessons)
- [ ] 5 Masāʾil recall for 3 random lessons
- [ ] Primary dalil + wajh for major topics
- [ ] Taṭbīq scenarios answered out loud
- [ ] All shubhāt logged and tracked
- [ ] Fahm >= 3 across lessons

## Beginner -> Intermediate
- [ ] Matn recall and explanation under random selection
- [ ] Architecture map of text sections
- [ ] 50+ active Anki cards
- [ ] Practical application across chapters
- [ ] Resolved lesson-level shubhāt

## Intermediate -> Advanced
- [ ] Precise mahall al-khilaf framing
- [ ] Usuli-guided tarjih with evidence chain
- [ ] Steelmanning opposing positions
- [ ] Dalil analysis (sanad + dalalah)
- [ ] Zero unresolved shubhāt in active track
