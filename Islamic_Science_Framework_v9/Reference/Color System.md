# 🎨 The Functional Color System — v9.0

> [!danger] MEMORIZE THIS PAGE BEFORE USING THE FRAMEWORK
> Every color carries exactly **one** meaning. Color outside its meaning and the system breaks.

---

## Color Reference

### 🔴 STOP / FOUNDATION

> [!danger] 🔴 Foundation
> **Means:** Foundation principles, action-required, things you MUST know before proceeding
> **Use it for:** Core principles, prerequisites, non-negotiable foundations
> **Never use it for:** Emphasis, decoration

### 🟡 MUST-KNOW-COLD

> [!warning] 🟡 Must-Know-Cold
> **Means:** Memory-critical content, Speed Spine, exam anchors, dalīl you recall without prompting
> **Use it for:** Speed Spine entries, core memorization targets
> **Never use it for:** Anything you can look up

### 🟢 HEART / SPIRITUAL

> [!tip] 🟢 Heart / Spiritual
> **Means:** Athar al-Qalb, duʿāʾ, khashyah, raghbah, ādāb, worship impact
> **Use it for:** Spiritual reflections, heart impact, duʿāʾ entries
> **Never use it for:** Academic content

### 🔵 EVIDENCE / DALĪL

> [!info] 🔵 Evidence / Dalīl
> **Means:** Qurʾān citations, ḥadīth, ijmāʿ, Salaf quotes, wajh al-dalālah
> **Use it for:** All evidence and proof-texts
> **Never use it for:** Principles, rulings, opinions

### 🟠 WARNING / DOUBT

> [!caution] 🟠 Warning / Doubt
> **Means:** Shubhāt, common errors, deviation traps, khataʾ log, conflict flags
> **Use it for:** Doubts, mistakes, warnings, error flags
> **Never use it for:** General attention-seeking

### 🟣 CROSS-REFERENCE

> [!abstract] 🟣 Cross-Reference
> **Means:** Links between subjects, rawābiṭ, see Lesson X, cross-subject notes
> **Use it for:** Bidirectional links, connections between lessons
> **Never use it for:** New content or analysis

### ⚫ REFERENCE ONLY

> [!quote] ⚫ Reference Only
> **Means:** Tafṣīl overflow, Expand-2 sections, source tracing — SKIP in Rapid Review
> **Use it for:** Deep-dive content, extended references
> **Never use it for:** Primary study content
