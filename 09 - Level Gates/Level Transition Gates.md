# 🚪 Level Transition Gates — No Feeling of Readiness. Demonstrated Mastery.

> [!danger] Every box must be checked before advancing. These are **performance tests**, not self-assessments.

---

## 🚪 Madkhal → Beginner

- [ ] **Speed Spine:** Recall any lesson's Speed Spine in 30 seconds when selected at random
- [ ] **Masāʾil:** List all 5 masāʾil (🔴🟡🟢🟠⚫) for 3 random lessons without notes
- [ ] **Dalīl:** Give the primary dalīl and its wajh for every major topic covered
- [ ] **Taṭbīq:** Answer all 4 scenarios for 2 random lessons out loud — no preparation
- [ ] **Feynman Test:** Explain any Madkhal topic to a non-Muslim friend — they understand it
- [ ] **Concept Chain:** Draw the entire Madkhal concept map from memory without notes
- [ ] **Shubhāt:** Every shubhāt from every Madkhal lesson has a written resolution
- [ ] **Fahm:** Rated ③ (Can Teach) or ④ (Own it) on every lesson — not just most
- [ ] **Ḥasb al-nafs:** Completed for every single lesson — all boxes checked
- [ ] **Cross-subject:** Have identified at least 3 connections between Madkhal content and another subject

> [!caution] ANY BOX UNCHECKED?
> Stay at the current level. Reinforce. Return when every box is checkable. Advancing early costs you more time than waiting costs you.

## 🚪 Beginner → Intermediate

- [ ] **Ḥifẓ:** Recite the entire matn from start to finish — no major errors
- [ ] **Sharḥ:** Explain the meaning of any line when selected randomly in real time
- [ ] **Architecture:** Explain where any line sits in the author's overall structure and why
- [ ] **Speed Spine:** 30-second recall of every bāb's theme
- [ ] **Dalīl:** Recall primary dalīl for every major section without notes
- [ ] **Terms:** Define every technical term introduced in the matn without looking
- [ ] **Application:** Apply the matn to 10 practical scenarios — at least 2 from each bāb
- [ ] **Anki:** 50+ Tier 1 and Tier 2 cards created and passing consistently
- [ ] **Shubhāt:** All confusions from all Beginner lessons have written resolutions
- [ ] **Fahm:** Rated ③ on all lessons — you can teach this matn to a beginner right now

> [!caution] ANY BOX UNCHECKED?
> Stay at the current level. Reinforce. Return when every box is checkable.

## 🚪 Intermediate → Advanced

- [ ] **Maḥall al-Khilāf:** State the precise locus of any dispute studied — without preparation
- [ ] **Tarjīḥ:** Give the rājiḥ position and full reasoning for every masʾalah covered
- [ ] **Steelmanning:** State any opposing view so accurately its proponents would agree
- [ ] **Uṣūl:** Name the uṣūl principle underlying every tarjīḥ you performed
- [ ] **Patterns:** Identify at least 3 recurring patterns across the masāʾil studied
- [ ] **Dalīl analysis:** Assess the strength of sanad and dalālah for any evidence cited
- [ ] **Application:** Apply any rājiḥ position to a new case not studied in class
- [ ] **Shubhāt:** Zero unresolved shubhāt — every entry in [[Master Shubhat Log|Master Log]] has a resolution
- [ ] **Fahm:** Rated ③–④ on all Intermediate lessons

> [!caution] ANY BOX UNCHECKED?
> Stay at the current level. Reinforce. Return when every box is checkable.
