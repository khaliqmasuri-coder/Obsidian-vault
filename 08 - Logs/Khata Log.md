## Root Cause Key

| Code | Meaning | What It Tells You |
|---|---|---|
| **M** | Memorization gap | You have not committed this to memory — increase Anki review |
| **A** | Application gap | You know the theory but cannot apply it — more Taṭbīq needed |
| **C** | Conceptual misunderstanding | You misunderstood the principle — re-study the lesson from scratch |
| **D** | Dalīl not known | You cannot cite the evidence — create Tier 2 Anki cards |
| **T** | Terminology confusion | You confused similar terms — add to [[Aqidah Vocabulary\|Vocabulary]] pages |
