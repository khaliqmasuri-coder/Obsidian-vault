# 📖 Fiqh — Arabic Technical Vocabulary

> [!info] You cannot master Islamic science without mastering its vocabulary. Learn the **definition**, not just the transliteration. Add to this list as you encounter new terms.

---

## Core Terms

| Term (Arabic) | Transliteration | Definition | My Example / Usage | First Seen | Mastered |
|---|---|---|---|---|---|
| فَرْض عَيْن | Farḍ ʿAyn | Individual obligation — every Muslim must perform | | Lesson #___ | - [ ] |
| فَرْض كِفَايَة | Farḍ Kifāyah | Collective obligation — fulfilled if some perform it | | Lesson #___ | - [ ] |
| سُنَّة | Sunnah (ruling) | Recommended action with reward for doing, no sin for leaving | | Lesson #___ | - [ ] |
| مُبَاح | Mubāḥ | Permitted — neither rewarded nor punished | | Lesson #___ | - [ ] |
| مَكْرُوه | Makrūh | Disliked — rewarded for leaving, no sin for doing | | Lesson #___ | - [ ] |
| حَرَام | Ḥarām | Prohibited — sin for doing, rewarded for leaving | | Lesson #___ | - [ ] |
| شَرْط | Sharṭ | Condition — must be met for the act to be valid | | Lesson #___ | - [ ] |
| رُكْن | Rukn | Pillar — essential component of an act | | Lesson #___ | - [ ] |
| وَاجِب | Wājib | Obligatory (in Ḥanbalī fiqh, one level below Farḍ ʿAyn) | | Lesson #___ | - [ ] |
| قِيَاس | Qiyās | Analogical reasoning — deriving rulings for new cases | | Lesson #___ | - [ ] |
